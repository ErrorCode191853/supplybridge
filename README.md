# SupplyBridge

SupplyBridge is a Java-based logistics and inventory
management learning project.

## Current Features
- Material domain model
- Unit of measure enumeration
- Material attribute validation
- Material identity and equality
- JUnit automated tests

## Planned Features
- Material catalog management
- Inventory and warehouse operations
- PostgreSQL persistence
- REST API with Spring Boot
- SAP integration

## Requirements
- JDK 21
- Maven

## Run Tests
```
mvn clean test
```
